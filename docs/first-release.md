## 완료

- 실제 생성 PNG를 사용하는 문구점 디자인, 교사·학생 화면
- 교사별 상점, 학급·모둠·학생 등록, 개인 입장 코드 발급·재발급
- 과제 등록, 과제별 모둠장 권한, 수행 확인과 포인트 적립·취소
- 상품 관리, 구매, 지급, 취소·환급, 포인트 원장과 CSV
- 실제 Firebase 프로젝트 `class-shop-f0f24` 생성. 무료 Spark 유지, 결제 계정 연결·유료 업그레이드 진행하지 않음
- Firestore Standard, 서울 `asia-northeast3` 생성. 테스트 모드 대신 기본 거부로 초기화
- Authentication Google·익명 제공업체 활성화
- Authentication 승인 도메인 `ajootree.github.io`가 Custom으로 저장된 것을 콘솔에서 확인
- Firestore 보안 규칙 게시 및 에뮬레이터 14개 권한·원자성 시나리오 통과
- 기본 도메인·체험 흐름 검사 5개 통과
- 배포 의존성 `npm audit --omit=dev`: 취약점 0개. 개발 도구의 별도 진단은 운영 번들에 포함하지 않음
- GitHub Actions 빌드와 GitHub Pages 배포 성공
- 브라우저 체험에서 과제 확인 → +5 포인트 → 구매 → 잔액·재고 차감 확인
- 제출용 개발 의도·실제 사용자 프롬프트 발췌·이미지 생성 프롬프트 보관

## 보류·추가 확인

- API 키 HTTP 리퍼러 제한: Google Cloud 최초 이용 화면에서 약관·상업적 사용 확인이 필수로 표시되어 사용자 결정 전 보류했다. 실제 주소 허용 목록 설정은 아직 완료하지 않았다. 국가·계정을 바꾸거나 다른 경로로 이 이용 조건을 우회하지 않았다.
- 실제 교사 로그인·학생 입장·온라인 저장의 전체 흐름은 다음 작업에서 재확인한다.
- 실제 학생 자료는 아직 입력하지 않았다. 교사 로그인 검수는 계정 선택·동의 화면까지 진행했으나 전체 완료를 검증하지 않았다.
- 태블릿과 스마트폰의 실제 기기 검수는 남아 있다.
- 따라서 이 버전을 모든 과제 보안 조건을 충족한 최종 제출본으로 표시하지 않는다. 현재는 1차 기능·디자인 검토용이다.

## 먼저 사용해 보기

배포 주소 → ‘가입 없이 먼저 둘러보기’ → ‘학생 지우’ 또는 ‘모둠장 서연’으로 역할 전환. 가상 학급 자료만 사용하며 실제 Firebase 학생 데이터와 분리된다.
