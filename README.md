# 수업상점

교사의 수업 과제 확인, 학생 포인트 적립, 보상 구매를 위한 웹앱입니다.

교사 화면의 ‘수업 도구’에서 타이머와 학생·모둠 발표 순서 뽑기를 선택해 각각의 화면에서 사용합니다. 순서 뽑기는 두구두구 효과음을 켜거나 끌 수 있습니다. 상품 그림은 12종에서 선택합니다. ‘퀴즈 관리’에서는 학급별 OX·4지선다·단답형 문제와 정답 보상을 설정하고 참여 결과를 확인합니다. 학생은 ‘퀴즈 도전’에서 문제당 한 번 제출하며 정답이면 포인트를 적립합니다.

‘CSV로 가져오기’에서 파일을 선택하거나 내용을 붙여넣고 미리 확인해 여러 퀴즈를 등록합니다. 필수 열은 `문제,정답`, 선택 열은 `포인트,유형,보기1,보기2,보기3,보기4`입니다. 양식을 내려받을 수 있습니다. 포인트 기본값은 10이며 한 번에 100문제, 파일은 512KB까지 지원합니다. UTF-8과 한국어 Windows CSV를 읽습니다. 같은 학급·문제·유형·보기·보상은 재가져오기 시 중복 생성하지 않으며 기존 정답을 덮어쓰지 않습니다. 5문제씩 저장하므로 중간 실패 시 같은 CSV로 재시도합니다. 단답형은 대소문자와 공백을 구분하지 않습니다.

## 실행

Node.js 24를 사용합니다.

```sh
npm ci --ignore-scripts
npm run build
npm run dev
```

로컬 주소: http://127.0.0.1:8842/

## Firebase와 배포

- Firebase 클라이언트 설정: `src/config.mjs`
- 인증: 교사 Google 로그인, 학생 Firebase 이메일/비밀번호 인증. 학생에게 실제 이메일을 받지 않습니다.
- 학생 가입·로그인: 학급 가입 코드, 이름, 비밀번호. 교사 승인 후 이용할 수 있습니다.
- 퀴즈 정답은 교사 전용 컬렉션에 분리합니다. 답안을 먼저 변경 불가 상태로 저장한 뒤, DB 규칙으로 채점·원장·잔액을 검증하여 중복 적립을 차단합니다. 연결이 끊겨 미채점으로 남은 답안은 학생의 ‘결과 확인’ 또는 교사의 미채점 확인으로 마무리합니다.
- Firestore 접근 규칙: `firestore.rules`. 규칙은 인증된 Firebase CLI에서 별도로 배포합니다.
- 웹 배포: `main` 변경 시 GitHub Actions가 검사·빌드 후 `dist/`를 GitHub Pages에 배포합니다.
- Firebase 인증 승인 도메인과 API 키의 HTTP 리퍼러 허용 목록에 실제 사용 주소를 등록해야 합니다. 데이터 권한은 Firestore 규칙에서 별도로 검증합니다.

## 검사

`npm test`로 기본 검사를 실행합니다. Firebase 인증·권한 검사는 Java 21 이상을 준비한 뒤 `npm run test:rules`로 실행합니다. 규칙 검사는 운영 데이터와 분리된 로컬 에뮬레이터를 사용합니다.
